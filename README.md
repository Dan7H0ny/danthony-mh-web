# Sitio web — DANTHONY MH

Sitio estático (HTML + CSS + JS, sin dependencias). Se publica gratis.

## 1. Antes de publicar (obligatorio)

1. **`main.js`** → al inicio, completa `CONFIG`:
   - El WhatsApp y el correo ya están configurados (codificados) en `_k`.
2. Cuando tengas la URL final, reemplaza `https://TU-DOMINIO.com` en
   `index.html`, `robots.txt` y `sitemap.xml`.

Para probar localmente: doble clic en `index.html`.

## 2. Publicar gratis (opción más fácil: Netlify)

1. Entra a https://app.netlify.com/drop
2. Arrastra **la carpeta completa** `danthony-mh-web`.
3. Te da una URL tipo `https://algo.netlify.app`. En *Site settings → Change site name*
   ponle `danthonymh` → `https://danthonymh.netlify.app`.

Alternativas gratuitas: Cloudflare Pages, GitHub Pages, Vercel.

**Dominio propio** (recomendado, ~$10–15/año): compra `danthonymh.com` en Cloudflare
o Namecheap y conéctalo en Netlify → *Domain management*. SSL es automático.

## 3. Aparecer en Google

1. https://search.google.com/search-console → agrega tu URL y verifícala.
2. Envía `sitemap.xml` en *Sitemaps*.
3. Crea un **Perfil de Empresa de Google** (Google Maps) con el enlace a la web.
4. Pon el enlace en LinkedIn, Facebook, Instagram y en tu estado de WhatsApp Business.

## 4. Conseguir clientes

- Regístrate en Workana, Freelancer, Upwork y Fiverr y enlaza esta web como portafolio.
- Agrega capturas reales de tus 3 proyectos en la sección *Proyectos* (`index.html`).
- Cuando tengas clientes, pide testimonios y agrégalos.
